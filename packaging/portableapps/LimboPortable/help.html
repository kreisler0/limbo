Limbo Portable

A lightweight browser, packaged in PortableApps.com Format.

Start Limbo with LimboPortable.exe or from the PortableApps.com Platform menu. Everything Limbo keeps (tabs, history, bookmarks, passwords, extensions, settings) stays in this package's Data folder. Limbo Portable writes nothing to the registry and nothing to your user profile.

Requirements

  • Windows 10 or 11, 64-bit.
  • The Microsoft Edge WebView2 Runtime, which is built into Windows 11 (and installed on most Windows 10 PCs by Windows Update). Limbo uses it as its engine; it isn't included in the package.

Good to know

  • Passwords are encrypted with your Windows account, so saved passwords only open when you're signed in to Windows as the same user (usually on the same PC). Export them first (Settings → Passwords → Export) before moving to another PC or account.
  • Default browser: a portable app can't register itself, so links from other apps keep opening in your usual browser.
  • Moving the package (another drive letter, another folder) is fine. Limbo re-registers its extensions from the new place on the next start; in rare cases an extension's own settings reset.
  • Run one copy of Limbo at a time. An installed Limbo and Limbo Portable open in the same window if both are running.
  • Downloads go to your Downloads folder unless you choose another in Settings → Downloads.

Updating

Install a newer LimboPortable_x.y.z_English.paf.exe over this one. Your Data folder is kept.
